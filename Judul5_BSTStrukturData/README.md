penjelasan:
Program ini merupakan sistem manajemen gerbang masuk konser otomatis berbasis Binary Search Tree (BST) yang terdiri dari komponen seperti (Class Node) sebagai penyimpan nomor tiket, 
fungsi registrasi (insert) untuk memosisikan tiket baru berdasarkan nilai (angka kecil di kiri, angka besar di kanan),
serta fungsi (search) untuk mengecek keaslian tiket secara instan dengan mengeliminasi setengah jalur pencarian di setiap tahap. 
Selain itu, ada 
inorder untuk urutan masuk dari yang terkecil,
preorder untuk struktur pohon, dan postorder).
program ini juga ada fungsi (find_min, find_max, count_nodes, dan sum_nodes) yang berguna untuk melacak tiket pertama/terakhir, menghitung total penonton, 
yang seluruhnya dikendalikan melalui menu interaktif
pada fungsi main dengan pengaman error handling (try-except).
