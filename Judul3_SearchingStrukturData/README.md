Kodingan ini bekerja dengan mengecek seluruh daftar nilai secara manual dari urutan pertama hingga terakhir untuk memastikan tidak ada data yang terlewat. Sistem menggunakan variabel indeks sebagai penunjuk posisi dan variabel penghitung untuk mencatat setiap kali ditemukan angka yang sama dengan nilai yang kamu cari. Di dalam perulangan while, program membandingkan nilai pada posisi saat ini dengan target, lalu jika cocok, angka pada penghitung akan bertambah satu sebelum sistem bergeser ke posisi berikutnya. Setelah semua data diperiksa, program akan melaporkan total jumlah kemunculan nilai tersebut secara akurat atau memberikan keterangan jika nilai tersebut tidak ada dalam database.
